ARDUINO NANO C++ FIRMWARE 16-CH PWM

LED Heart Keychain

An Arduino Nano-based 16-LED display featuring smooth PWM breathing, ECG waveform tracing, and shatter animations. Driven entirely by non-blocking software polling and a single button.

Source Code
PROJECT: HEART-16

Firmware Architecture

  • > Non-blocking polling: A custom smartDelay() checks the button every 1ms, allowing instant animation switching mid-cycle.
  • > Internal Pull-ups: Zero external resistors needed for the tactile switch. Uses `INPUT_PULLUP`.
  • > Hardware PWM: Utilizes pins 5, 6, 9, 10, 11 for smooth 8-bit brightness fading.
  • > Micro-optimized: Compiles to ~7KB flash, well within limits.

MAIN.CPP

Non-Blocking Loop

To ensure animations instantly jump to the next mode when the user presses the button, traditional delay() cannot be used. We use a custom polling function. 

// Intercepts delay to poll button state
bool smartDelay(int delayTime) {
  unsigned long start = millis();
  while (millis() - start < delayTime) {
    // Read pin (LOW due to PULLUP)
    if (digitalRead(BTN_PIN) == LOW) {
      delay(30); // Debounce
      if (digitalRead(BTN_PIN) == LOW) {
        currentMode++;
        if (currentMode > 16) currentMode = 1;
        clearAllLEDs();
        // Wait for release
        while(digitalRead(BTN_PIN) == LOW); 
        return true; // Break loop
      }
    }
  }
  return false;
}
